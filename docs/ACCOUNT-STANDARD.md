# KURO 共通アカウント規格 v1.0

最終更新：2026-11-21

KURO Lab・KURO SNS・KURO GAMESは、同じSupabase Authアカウントと同じプロフィールを利用する。サービスごとに別のユーザー名や表示名を作らない。

## 1. ユーザーを識別する2つの値

| 項目 | DB列 | 役割 | 変更 |
|---|---|---|---|
| ユーザーネーム | `public.profiles.username` | 検索、ログイン、投稿者・プレイヤー表示に使用する名前 | 変更可能 |
| KURO ID | `public.profiles.kuro_id` | KUROサービス全体で共通の公開ID | 変更不可 |

公開IDは `KURO-` + 16桁の大文字16進数。ユーザー作成時に自動発行し、サービス移動・ユーザーネーム変更・投稿・ランキング更新でも変更しない。

## 2. ユーザーネームの規則

- 3〜24文字。
- 半角英字、半角数字、アンダースコア（`_`）のみ。
- 大文字・小文字を区別せず一意とする（`Kuro` と `kuro` は同一扱い）。
- 画面上では原則 `@username` と表示する。
- ユーザーネームを変更してもKURO ID、認証アカウント、投稿、ゲーム記録は変更・再作成しない。

## 3. 内部IDとデータ設計

- `auth.users.id`（UUID）はSupabase内部の外部キーとして維持する。公開プロフィールIDとして表示したり、ユーザー間の検索キーとして公開したりしない。
- `profiles.id` は `auth.users.id` を参照する内部キー。
- `profiles.username` が唯一の正規ユーザーネーム。
- `profiles.kuro_id` が唯一の公開固定ID。
- `display_name` は旧画面・旧APIの互換性のためだけに残す。トリガーで常に `username` と同じ値に同期し、別の名前として編集・利用しない。
- 自己紹介、プロフィール画像などの追加プロフィール情報は、ユーザー識別子とは別の任意情報として扱う。

## 4. サービス共通ルール

### KURO Lab
- 共通Supabase Authでログインする。
- マイページに `@username` とKURO IDを表示する。
- アカウント作成時に表示名を別途要求しない。

### KURO SNS
- 新規登録・プロフィール編集で設定する識別名はユーザーネーム1つだけ。
- 投稿者、返信者、検索結果、プロフィールに同じユーザーネームを使う。
- KURO IDはプロフィール上で表示する。

### KURO GAMES
- KURO Lab / KURO SNSと同じ認証セッション・プロフィールを利用する。
- ゲーム登録画面で表示名を別途要求しない。
- ゲーム内プレイヤー名・ランキング名は共通ユーザーネームを使う。
- ランキングやオンライン参加者に渡す公開IDはKURO IDを使う。

## 5. 認証ルール

- 認証主体は共通のSupabase Authユーザー。
- メールアドレスまたはユーザーネームでログインできる導線を提供する。
- ユーザーネーム検索は `public.profiles` を正とする。別のユーザー名台帳を正規データにしない。
- アカウント作成後はAuthユーザー作成トリガーでプロフィールを作成する。
- ユーザーネーム更新はプロフィール行を更新し、KURO IDは変更しない。
- 認証・権限判定は `auth.uid()` / 内部UUIDで行い、ユーザーネームやユーザーメタデータを権限判定に使わない。

## 6. 旧仕様からの互換性

旧 `display_name` 列およびゲームAPIの `display_name` / `displayName` は、旧クライアントを壊さないための一時的な互換エイリアスとしてのみ残せる。返す値は必ず `username` と同じにする。新規実装では使わず、`username` と `kuroId` を読む。

旧 `kuro_username_accounts` テーブルは正規プロフィールの代替にしない。ログイン・登録・ユーザー検索は `profiles` を使う。

## 7. 変更時の確認項目

- ユーザーネームが大文字小文字を無視して一意である。
- 既存ユーザーの `auth.users.id` とKURO IDが保持される。
- ユーザーネーム変更後、3サービスすべてで同じ名前が表示される。
- 変更前後で投稿、フォロー、チャット、スコア、勝利記録、オンライン履歴が同じ内部ユーザーIDに紐づく。
- 旧APIを使うゲームに返す互換エイリアスもユーザーネームと一致する。
