# KURO Lab（クロラボ）

KURO Lab（KURO Lab / クロラボ）は、オリジナルのWebサービスやブラウザゲームを企画・開発・運営するプロジェクトです。

**公式サイト： https://kurolab.cc.cd/**

## サービス

- **KURO SNS** — 短い投稿、ハッシュタグ、フォロー、返信、チャットで交流できるソーシャルサービス  
  https://kurolab.cc.cd/sns/
- **KURO GAMES** — インストール不要で遊べる無料ブラウザゲームの一覧  
  https://kurolab.cc.cd/games/

### KURO GAMESのゲーム

- 回転寿司タイピング — https://kurolab.cc.cd/game/kaiten-sushi-typing/
- ブロックブラスト — https://kurolab.cc.cd/game/block-blast/
